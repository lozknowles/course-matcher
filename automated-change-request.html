AUTOMATED CHANGE REQUEST

Show the agent doing the work

This prototype models a staff-approved automation route through a ProSolution-style Student Change Request queue. The agent filters the work list, opens the next request, accepts the change, saves the updated student record and then removes that Change Request ID from the visible queue.

Demonstration boundary

The flow is intentionally synthetic. A production implementation would need CIS approval, supported authentication, role permissions, reconciliation/read-back, failure handling and a full audit trail. It should not bypass native controls.
